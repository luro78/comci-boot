# 컴시간 접속 정보 자동 수집

30분마다 화면 없는 크롬으로 컴시간 알리미를 열어 학교를 검색·선택하고,
그때 오가는 요청 주소에서 접속 정보(주소·검색 번호·앞부분·꼬리)를 알아내 `comci-boot.json`에 저장합니다.

- 값이 바뀌었을 때만 저장(커밋)합니다.
- 수업·담임 기록장 통합판의 설정 탭 → 컴시간 연동 → "내 접속 정보 주소"에 이 저장소 주소를 넣으면 이 값을 씁니다.
- 실패하면 GitHub가 저장소 주인에게 메일로 알려 줍니다.

파일
- `comci_capture.py` : 수집 프로그램 (파이썬 기본 기능만 사용)
- `.github/workflows/comci-boot.yml` : 30분마다 실행하는 설정
- `comci-boot.json` : 알아낸 접속 정보 (자동 생성)
